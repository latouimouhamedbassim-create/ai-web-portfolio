## ✨ Highlights

- **Responsive** – layout adapts from phones to large desktops (CSS Grid + `clamp()` typography).
- **Automatic dark / light mode** using `prefers-color-scheme`.
- **Smooth UX** – sticky blurred navbar, scroll-reveal animations, hover micro-interactions.
- **Lightweight** – no frameworks, no build step, loads instantly.
- **SEO-ready basics** – semantic HTML, meta description, proper heading hierarchy.
- **Accessible** – good contrast, keyboard-friendly links, `rel="noopener"` on external links.

## 📁 Structure

```
ai-web-portfolio/
├── index.html   # page content and sections
├── style.css    # design tokens, layout, dark/light themes
└── script.js    # footer year + scroll animations
```

## 🚀 Run locally

```bash
git clone https://github.com/latouimouhamedbassim-create/ai-web-portfolio.git
cd ai-web-portfolio
python -m http.server 8000      # then open http://localhost:8000
```

## ☁️ Deploy on GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under *Build and deployment*, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**, then **Save**.
4. After about a minute the site is live at `https://<username>.github.io/ai-web-portfolio/`.

## 🎨 Customize

All colors live in CSS variables at the top of `style.css` (`--accent`, `--accent2`, `--bg`…). Edit the text in `index.html` to make it yours.
